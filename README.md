PySA (Pythonic Statistical Analysis) is a set of Python scripts for the analysis of data by basic statistical and machine learning methods (under development).

How it works:
PySA assumes that each data set is in a single plaintext or csv file and that the data is organized into columns x1 to xn, y, group, annotation. In csv files, the first line contains the column labels. Results, out files, graph images, are stored in the same working directory as the analysed data.
